# KG-1 — лабораторная работа по компьютерной графике

Программа позволяет создавать наборы треугольников с помощью OpenGL и FreeGLUT, выбирать и редактировать отдельные примитивы, перемещать наборы и изменять порядок их отрисовки.

## Запуск проекта

1. Открыть `KG-1.sln` в Visual Studio 2022.
2. При необходимости восстановить NuGet-пакеты решения. В проекте используется пакет `freeglut.3.2.2.v140`.
3. Выбрать конфигурацию `Debug` или `Release` и платформу `x64` либо `x86`.
4. Собрать и запустить проект.

## Основной принцип работы

Программа работает в двух режимах:

- `DRAW` — создание треугольников и работа с наборами;
- `EDIT` — выбор и редактирование отдельного треугольника текущего набора.

Текущий режим и выбранные объекты отображаются в заголовке окна. Переключение между режимами выполняется клавишей `F2`.

В режиме `DRAW` каждый щелчок левой кнопкой мыши добавляет вершину. Каждые три вершины образуют отдельный треугольник. Клавиша `Space` завершает текущий набор и создаёт новый. Незавершённый треугольник при этом удаляется.

Контекстное меню открывается правой кнопкой мыши и автоматически меняется в зависимости от текущего режима.

## Общее управление

| Действие | Управление |
| --- | --- |
| Переключить `DRAW` / `EDIT` | `F2` |
| Переместить текущий объект | стрелки или `W`, `A`, `S`, `D` |
| Установить красный цвет | `R` или `1` |
| Установить зелёный цвет | `G` или `2` |
| Установить синий цвет | `B` или `3` |
| Вернуть текущий объект в исходное положение | `Home` |
| Открыть контекстное меню | правая кнопка мыши |

Под текущим объектом понимается набор в режиме `DRAW` и выбранный треугольник в режиме `EDIT`.

Перемещение ограничено рабочей областью окна: объект нельзя полностью или частично увести за её границы.

## Режим DRAW

| Действие | Управление |
| --- | --- |
| Добавить вершину | левая кнопка мыши |
| Создать новый набор | `Space` |
| Выбрать предыдущий набор | `Page Up` |
| Выбрать следующий набор | `Page Down` |
| Удалить последний примитив | `Backspace` |
| Удалить последний набор | `Delete` или `X` |
| Поднять набор на один слой | `Ctrl + ↑` |
| Опустить набор на один слой | `Ctrl + ↓` |
| Поместить набор поверх остальных | `Ctrl + Home` |
| Поместить набор под остальные | `Ctrl + End` |

Изменение цвета в режиме `DRAW` задаёт цвет набора и всех находящихся в нём треугольников. Пустой набор автоматически не удаляется: программа сообщает о нём в заголовке окна.

Удалить именно активный набор можно через контекстное меню.

## Режим EDIT

| Действие | Управление |
| --- | --- |
| Выбрать предыдущий треугольник | `Page Up` или `Shift + Tab` |
| Выбрать следующий треугольник | `Page Down` или `Tab` |
| Удалить выбранный треугольник | `Backspace` |
| Поднять треугольник на один слой внутри набора | `Ctrl + ↑` |
| Опустить треугольник на один слой внутри набора | `Ctrl + ↓` |
| Поместить треугольник поверх остальных в наборе | `Ctrl + Home` |
| Поместить треугольник под остальные в наборе | `Ctrl + End` |

Выбранный треугольник выделяется жёлтым контуром и увеличенными точками вершин. Изменение положения и цвета применяется только к нему. Треугольник остаётся частью своего набора даже при изменении порядка отрисовки.

## Порядок отрисовки

У программы два уровня порядка:

1. Порядок наборов определяет, какой набор отображается поверх другого.
2. Порядок примитивов определяет расположение треугольников только внутри одного набора.

Изменение порядка не меняет последовательность создания объектов, поэтому команда удаления последнего примитива продолжает относиться к последнему созданному примитиву.
